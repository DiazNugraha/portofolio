# Readiness Index @ INCIT

This project is an assessment platform designed to evaluate industrial transformation readiness. It brings together several applications that the company has developed into a single platform.

### Challenge

This app is intended to be used by people from different countries around the world. Since English may not be the primary language for many of its users, Localization is important to make the app easier and more comfortable to use.

Localization using Tolgee had already been implemented, but its main capabilities had not been fully utilized.

### My Work

- Developed the application across backend services and frontend implementation.
- Standardized the internationalization approach across applications using self-hosted Toglee and NestJs i18n library.

### Technologies

- React Js
- Nest Js
- Postgresql
- Vite
- Tolgee localization platform
