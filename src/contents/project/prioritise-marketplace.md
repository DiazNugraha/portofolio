# Prioritise+ Marketplace @ INCIT

I worked on this project after my probation period. What was special about this project was that some of its pages would be attached to other applications.

This led me to think, “What if we didn’t have to write the same page again and again in each application?” I imagined that the page could be written in a single source and then shared with other applications, so any updates made to the source would also be reflected in the other applications.

With this approach, we could avoid copying and pasting the same page across multiple applications that need to display it. have worked on this project after my probation times. What special on this project is this project will be applied some page that will be attached in another app. So then, come up with an idea "what if we not writing the page on the other app again and again", im imagining this page could be just written in one source and will affect the other app to get the update once the source get updated. So with this idea it will avoid copy paste over each app that should be displaying the page.

### My Work

- Implemented micro frontend integration using Vite Plugin Federation to enable shared functionality across applications.
